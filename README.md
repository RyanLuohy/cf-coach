# CF 教练 · 网页版（PWA）

不用 Mac、不用开发者账号、不用 $99。装到 iPhone 主屏幕后，用起来和 App 差不多。

---

## 一、它能做什么，不能做什么

| 能做 | 不能做 |
|---|---|
| 每天看练什么、吃什么、注意事项 | ❌ 自己读 HealthKit（iOS 只允许原生 App 读） |
| 12 周 48 次训练、7 天餐单，离线可用 | ❌ 后台自动推送通知（iOS 限制） |
| 打卡、周完成率、恢复评分 | ❌ 在表盘上显示 |
| 按睡眠/心率/HRV 给训练调整建议 | |

**缺的两块，用系统功能补上：**

- 健康数据 → **快捷指令**读 HealthKit，复制成一段文本，App 里点一下导入
- 定时提醒 → **导入日历**（`.ics`），通知会同步到 Apple Watch

## 二、装到手机（约 15 分钟）

### 第 1 步：把 `CFApp` 传到网上（二选一）

**A. GitHub Pages（免费、永久、推荐）**

1. 打开 [github.com](https://github.com) 注册（免费）；
2. 右上角 **+ → New repository**，名字填 `cf-coach`，选 **Public**，Create；
3. 仓库页点 **uploading an existing file**，把 `CFApp` 文件夹里的**所有文件和 icons 文件夹**拖进去，Commit；
4. 仓库 **Settings → Pages** → Source 选 **Deploy from a branch** → Branch 选 **main**、目录选 **/(root)** → Save；
5. 等 1–2 分钟，访问 `https://你的用户名.github.io/cf-coach/`。

**B. Netlify Drop（更快，需注册保留）**

1. 打开 [app.netlify.com/drop](https://app.netlify.com/drop)；
2. 把整个 `CFApp` 文件夹拖进页面；
3. 得到 `https://xxxx.netlify.app`，注册登录以保留站点。

> PWA 必须走 `https://`，所以不能直接双击本地文件打开。

### 第 2 步：添加到主屏幕

1. iPhone 用 **Safari** 打开上面的网址；
2. 点底部 **分享** → **添加到主屏幕**；
3. 名字写「CF 教练」→ 添加。

打开后是全屏的，没有地址栏，和 App 一样，且断网也能用。

### 第 3 步：导入每日提醒（7:20 一条）

**先建一个专用日历**（否则 51 条会混进个人日历）：

1. 日历 App → 底部「日历」→「编辑」→「添加日历」→ 名称 **CF 教练**；
2. 设置 → **App → 日历**（iOS 17 及更早：设置 → 日历）→ **默认日历** → 选 CF 教练。
   找不到就用设置顶部搜索框搜「默认日历」。

**再导入文件**：

1. 把 `CF-提醒-每日.ics` 发到 iPhone（微信/邮件/AirDrop），存到「文件」App；
2. 点开 → 底部「**添加全部 51 个日程**」；
3. 打开任意一条，确认「日历」显示 **CF 教练**。

**每天只有 07:20 一条**，训练和吃的都在里面：

| 类型 | 条数 | 内容 |
|---|---|---|
| 训练日 | 48（单次事件） | 当周的真实重量 + 当天全部餐食 + 注意事项 |
| 休息日 | 3（每周重复） | 休息建议 + 当天餐食 |

点开一条能看到完整内容，比如 W5 周一：

> **练** 下肢力量 + 有氧底子（90 分钟）
> 背蹲 5×3 @82.5 · 硬拉 4×3 @100 · 20min Zone2
> **吃** 早 燕麦70 牛奶300 鸡蛋50 蛋白100
> 　　 午 米饭270 鸡胸145 西兰花200
> 　　 全天 2395 kcal · 蛋白 178g

> 训练日为什么用「单次事件」而不是重复事件？因为**每周重量不一样**，单次事件才能写死当周的数字。
> 休息日用重复事件，因为内容不随周次变化。

日期从 **2026-11-09（周一）** 开始，到 2027-01-30 结束。开始日期不是这天的话告诉我，我重算。

## 四、今天不练 / WOD 成绩 / 每周复盘

### 1. 「今天练 / 今天不练」

「今天」页最上面有一个开关：

- **今天练** → 显示课表内容，餐食用训练版
- **今天不练** → 这节课记为**跳过**（不算完成、也不算缺勤），餐食自动切到**休息版**

休息版的数字是单独算的，不是拍脑袋：

| | 训练版 | 休息版 |
|---|---|---|
| 热量 | 2395 kcal | **2104 kcal**（−290） |
| 蛋白 | 178 g | **176 g**（不变） |
| 碳水 | 284 g | **222 g**（−62） |
| 餐数 | 6 餐 | 4 餐（去掉训练前/后的加餐） |

蛋白不降是关键——不练的那天最容易吃不够蛋白，然后掉的是肌肉。

如果是**休息日**却想练，切到「今天练」会显示「自选训练」：30–40 分钟 Zone2 + 活动度 + 平板，并提醒你训练前后各加一份碳水。

### 2. WOD 成绩

训练日当天，训练清单下面就是记录卡：

- 类型选 **计时**（填分:秒）或 **AMRAP**（填轮数 + 额外次数）
- RPE 6–10，备注写降阶方式（例：哑铃 2×15kg，最后一轮拆 4-3-3）
- 保存后当天显示成绩，可删除重填

记录会进入「数据」页的成绩列表，也是每周复盘的依据。**同一个 WOD 用同一个降阶重测**，数字才有意义。

### 3. 每周复盘（自动生成）

「数据」页最上面是复盘卡，可以切「本周 / 上周」，内容全部按你的记录自动算：

- 完成 X/4 次、跳过几次
- 这周记录了几条 WOD 成绩
- 睡眠均值 + 最低的一晚
- 静息心率、HRV 与 14 天基线的对比
- 步数均值
- 体重变化（周初 → 周末）

下面会跟 2–4 条建议，规则是固定的：

| 条件 | 建议 |
|---|---|
| 完成率 < 50% | 把训练日固定成周几，别当天决定 |
| 跳过 ≥ 2 次 | 排太满了，下周先按每周 3 天走 |
| 有一晚 < 6.5h | 那天本该砍掉代谢训练 |
| 静息心率整周 +5 | 下周安排减量周 |
| 步数均值 < 7000 | 减脂主要靠步数 |
| 体重 +0.3kg 以上 | 先查饮食，别急着加训练量 |

## 五、每天怎么用

| 时间 | 动作 |
|---|---|
| 07:20 | 看日历通知：今天练什么、三餐吃什么 |
| 早上 | 打开 App → 导入健康数据 → 看恢复评分和注意事项 |
| 出门前 | 决定「今天练 / 今天不练」——不练就自动切休息版餐单 |
| 训练前 | 看「今天」的训练清单，按重量执行 |
| 每餐 | 吃完点一下打勾 |
| 训练后 | 标记完成 + 填 WOD 成绩（时间或轮数） |
| 睡前 | 「数据」看本周复盘 |

恢复评分的规则和原计划一致：

- 睡眠 < 5.5h → 建议只做活动度或休息
- 睡眠 < 6.5h → 砍掉代谢/间歇
- 静息心率比基线高 ≥8 → 加一天休息或改 Zone2
- HRV 比基线低 20% → 主项降 20%
- 18:00 后步数 < 6000 → 提醒补步数

基线来自你过去最多 14 条的记录，所以**至少要用三天**，心率那两项才准。

## 七、常见问题

**Q：为什么不能像 App 一样自动读健康数据？**
A：HealthKit 是原生能力，网页没有权限。这是苹果的限制，不是实现问题。要全自动只有原生 App（需要 Mac + $99/年）。

**Q：为什么不能直接推送通知？**
A：iOS 对网页 App 的通知限制很严，需要服务器推送。用日历代替是最稳的免费方案，而且能同步到手表。

**Q：在 Safari 里打开和主屏幕 App 数据一样吗？**
A：不一样。iOS 上主屏幕 App 是独立存储。**只用主屏幕那个**，否则会看到两份数据。

**Q：计划改了怎么办？**
A：重新导出一份 `plan.json` / `menu.json` 覆盖仓库里的同名文件，刷新一次即可。

**Q：能看 WOD 成绩吗？**
A：目前没有成绩记录入口。需要的话我下一版加。
